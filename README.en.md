# 🧮 BMI Calculator Screen

A mobile app built with Flutter with two main features: basic math operations and BMI (Body Mass Index) calculation.

---

## 📱 Screens

| Home Screen | Math Operations | BMI Calculator |
|---|---|---|
| Navigation menu | Addition, subtraction, multiplication and division | BMI calculation and classification |

---

## ✨ Features

- **Home Screen** — navigation between the app's features
- **Math Operations** — performs basic calculations (addition, subtraction, multiplication and division)
- **BMI Calculator** — calculates Body Mass Index and displays the result's classification

---

## 🛠️ Technologies

- [Flutter](https://flutter.dev/)
- [Dart](https://dart.dev/)

## 🚀 How to Run

**Prerequisites:** Flutter installed. See how at [flutter.dev](https://docs.flutter.dev/get-started/install).

```bash
# Clone the repository
git clone https://github.com/LuizPauloSoares/tela-imc-calculadora.git

# Enter the folder
cd tela-imc-calculadora

# Install dependencies
flutter pub get

# Run the app
flutter run
```
