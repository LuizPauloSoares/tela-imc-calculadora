# 🧮 Tela IMC Calculadora

Aplicativo mobile desenvolvido em Flutter com duas funcionalidades principais: cálculo de operações matemáticas básicas e cálculo de IMC (Índice de Massa Corporal).

---

## 📱 Telas

| Tela Inicial | Operações Matemáticas | Calculadora de IMC |
|---|---|---|
| Menu de navegação | Soma, subtração, multiplicação e divisão | Cálculo e classificação do IMC |



---

## ✨ Funcionalidades

- **Tela Inicial** — navegação entre as funcionalidades do app
- **Operações Matemáticas** — realiza cálculos básicos (soma, subtração, multiplicação e divisão)
- **Calculadora de IMC** — calcula o Índice de Massa Corporal e exibe a classificação do resultado

## 🚀 Como rodar o projeto

**Pré-requisitos:** ter o Flutter instalado. Veja como em [flutter.dev](https://docs.flutter.dev/get-started/install).

```bash
# Clone o repositório
git clone https://github.com/LuizPauloSoares/tela-imc-calculadora.git

# Entre na pasta
cd tela-imc-calculadora

# Instale as dependências
flutter pub get

# Rode o app
flutter run
```
